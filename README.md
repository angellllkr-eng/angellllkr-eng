## Operating standard

**Evidence before claims.** Every deployment is HTTP-verified. Every status is VERIFIED, READY, BLOCKED, FAILED, or UNVERIFIED — never guessed.

**One product = one repo.** No scattered duplicates. Each product has its own voice, visual grammar, and job to be done.

**Secrets stay local.** Never committed, never exposed, never sent to third-party AI.

**Reversible by default.** Important actions have checkpoints and require explicit approval.
